# Constellation Workspace

This is the default writable scratch area for Constellation on a fresh clone.

- `scratch/` for temporary experiments and generated artifacts
- `repos/` for cloned or staged coding targets
- `notes/` for working notes generated during sessions
- `exports/` for outputs you want to keep outside the main archive

Machine-specific runtime settings live in `toolbelt/runtime_paths.json`, which is intentionally not tracked by Git.
